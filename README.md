# .github

Standard-Dateien für alle Repositories von roberteinsle.

- `STANDARDS.md` – gemeinsame Regeln für alle Apps (Original; Kopie in `app-template/docs/`)
- `DEPLOYMENT.md` – Betriebshandbuch: Einrichtung, Coolify, Deploy, Rollback, PHP-Updates
- `NEUES-REPO.md` – Checkliste für neue Projekte
- `SECURITY.md` – gilt automatisch für alle Repos ohne eigene SECURITY.md
- `prompts/login-audit.md` – Prüfauftrag für den Login (Original; Kopie in `app-template/.claude/commands/`)
- `scripts/github-security-enable.sh` – schaltet Security-Funktionen in allen Repos ein
- `vorlagen/dependabot.yml` – Vorlage für Abhängigkeits-Updates
