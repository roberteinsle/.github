# Sicherheit

Sicherheitslücken bitte **nicht** als öffentliches Issue melden.

## Eine Lücke melden

Bitte im betroffenen Repository über **Security → „Report a vulnerability“** melden (private Sicherheitsmeldung). Hilfreich sind:

- was betroffen ist (Datei, Funktion, Version),
- wie sich die Lücke nachvollziehen lässt,
- was ein Angreifer damit erreichen kann.

Bitte keine fremden Systeme oder Instanzen angreifen – zum Nachvollziehen reicht eine eigene Testumgebung.

## Was danach passiert

- Eingangsbestätigung innerhalb von 7 Tagen.
- Bestätigte Lücken werden vorrangig behoben.
- Wer die Lücke gemeldet hat, wird auf Wunsch genannt.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es für den jeweils aktuellen Stand des Standard-Branches bzw. das neueste Release.

Projekte mit eigener `SECURITY.md` (z. B. openwehr) haben eigene Regeln – dort gilt die Datei im jeweiligen Repository.
